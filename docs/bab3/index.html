3.2.1 Diagram Flowchart Alur Manual (Konvensional)

Pemetaan alur jual-beli antar siswa sebelum sistem sNaps diimplementasikan

flowchart TD
    NodeStart([Mulai: Siswa Ingin Menjual Produk/Karya]) --> NodeUpload[Siswa Mengambil Foto & Membuat Teks Promosi Manual]
    NodeUpload --> NodeBroadcast[Unggah ke Status WhatsApp & Grup Angkatan]
    NodeBroadcast --> NodeWait[Menunggu Respon Chat Calon Pembeli]
    
    NodeWait --> NodeConditionResponse{Apakah Ada Siswa yang Membalas Chat?}
    NodeConditionResponse -- Tidak (Tenggelam) --> NodeExpired[Postingan Hilang dalam 24 Jam / Tanpa Hasil Penjualan]
    NodeExpired --> NodeEndCancel([Selesai / Transaksi Batal])
    
    NodeConditionResponse -- Ya --> NodeNegotiate[Tanya Jawab Manual via DM: Tanya Ketersediaan Stok & Nego Harga]
    NodeNegotiate --> NodeConditionDeal{Apakah Tercapai Kesepakatan Harga?}
    NodeConditionDeal -- Tidak Sepakat --> NodeEndCancel
    
    NodeConditionDeal -- Sepakat --> NodeAppointment[Menentukan Waktu & Janji Temu Lokasi via Chat Teks]
    NodeAppointment --> NodeRisk[Rawan Miskomunikasi: Siswa Salah Lokasi Lantai / Jam Bentrok / Ghosting]
    
    NodeRisk --> NodeMeet[Kedua Siswa Bertemu Secara Fisik di Area Sekolah]
    NodeMeet --> NodeInspect[Pembeli Memeriksa Fisik Barang Secara Langsung]
    NodeInspect --> NodePay[Pembeli Menyerahkan Uang Tunai / Cash]
    NodePay --> NodeReceipt[Penjual Menghitung Kembalian & Menyerahkan Barang Fisik]
    NodeReceipt --> NodeManualRecord[Penjual Mencatat Penjualan di Buku Catatan Kertas / Catatan HP Pribadi]
    NodeManualRecord --> NodeEndSuccess([Selesai: Transaksi Manual Berhasil])

3.2.2 Diagram Flowchart Alur Sistem Digital (sNaps)

Alur autentikasi NIS, publikasi karya vokasi, pemesanan via Chat DM, dan transaksi tunai di spot COD

flowchart TD
    Start([Mulai: Siswa Buka Snaps]) --> CheckAuth{Sudah Login?}
    
    %% Alur Login Sederhana
    CheckAuth -- Belum --> FormLogin[Input NIS & Password]
    FormLogin --> ValidasiLogin[(Validasi ke student_registry)]
    ValidasiLogin --> Beranda[Masuk ke Halaman Beranda]
    CheckAuth -- Sudah --> Beranda

    %% Pilihan Menu Utama
    Beranda --> PilihAksi{Pilih Aktivitas}

    %% JALUR 1: JUAL KARYA (KIRI)
    PilihAksi -- Jual Produk / Karya --> FormJual[Buka Form Buat Postingan]
    FormJual --> InputJual[Input Foto, Judul, Kategori Jurusan & Harga]
    InputJual --> SimpanPost[(Simpan ke Database PostgreSQL)]
    SimpanPost --> TayangPost[Produk Tayang di Beranda]
    TayangPost --> SelesaiJual([Selesai])

    %% JALUR 2: BELI PRODUK (KANAN)
    PilihAksi -- Beli Produk --> BukaDetail[Buka Halaman Detail Produk]
    BukaDetail --> KlikBeli[Tekan Tombol 'Beli Sekarang']
    KlikBeli --> MasukChat[Langsung Masuk ke Ruang Chat DM Penjual]
    MasukChat --> TempelProduk[Sistem Otomatis Melampirkan Kartu Produk di Chat]
    TempelProduk --> NotifPenjual[Kirim Push Notifikasi Chat ke HP Penjual]
    NotifPenjual --> JanjianCOD[Kedua Siswa Diskusi & Janjian Titik Temu COD]
    JanjianCOD --> KetemuCOD[Bertemu Fisik di Area Sekolah Pas Jam Istirahat]
    KetemuCOD --> BayarTunai[Pembeli Cek Kondisi Barang & Bayar Tunai]
    BayarTunai --> SelesaiBeli([Selesai: Transaksi Berhasil])

3.10.1 Sequence Diagram: Registrasi Akun Siswa (Verifikasi NIS)

Alur pesan kronologis registrasi akun baru dengan validasi buku induk sekolah

sequenceDiagram
    autonumber
    actor Siswa as 👤 Siswa Pendaftar
    participant UI as 📱 RegisterScreen
    participant Ctrl as 🎮 AuthController
    participant Svc as 🌐 SupabaseAuthService
    participant DB_Reg as 🗄️ student_registry (Buku Induk)
    participant Auth_Svr as 🔐 Supabase Auth (auth.users)
    participant DB_Prof as 🗄️ profiles (Data Akun)

    Siswa->>UI: Input NIS, Username, Password, & Konfirmasi
    UI->>Ctrl: registerWithNis(nis, username, password)
    activate Ctrl
    
    Ctrl->>Svc: executeRegistration(payload)
    activate Svc
    
    %% TAHAP 1: VALIDASI BUKU INDUK
    Svc->>DB_Reg: SELECT * FROM student_registry WHERE nis = :nis AND is_active = true
    activate DB_Reg
    alt NIS Tidak Terdaftar / Tidak Aktif di SMKN 8
        DB_Reg-->>Svc: Data Kosong (0 Row)
        deactivate DB_Reg
        Svc-->>Ctrl: Throw Error: 'NIS tidak valid sebagai siswa aktif SMKN 8'
        Ctrl-->>UI: Emit State Error (NIS Ilegal)
        UI-->>Siswa: Tampilkan Dialog Penolakan: 'NIS Tidak Terdaftar'
    else NIS Terdaftar Valid
        DB_Reg-->>Svc: Record Siswa (Nama Lengkap, Kelas, Jurusan)
        
        %% TAHAP 2: CEK DUPLIKASI AKUN
        Svc->>DB_Prof: SELECT id FROM profiles WHERE nis = :nis
        activate DB_Prof
        alt NIS Sudah Pernah Didaftarkan Sebelumnya
            DB_Prof-->>Svc: Record Ditemukan (Duplikat)
            deactivate DB_Prof
            Svc-->>Ctrl: Throw Error: 'NIS ini sudah memiliki akun aktif'
            Ctrl-->>UI: Emit State Error (Akun Duplikat)
            UI-->>Siswa: Tampilkan Peringatan: 'Akun Sudah Ada, Silakan Login'
        else NIS Belum Pernah Didaftarkan (Fresh Account)
            DB_Prof-->>Svc: Data Kosong
            
            %% TAHAP 3: PEMBUATAN AKUN SUPABASE AUTH
            Svc->>Auth_Svr: signUp(email: nis@smkn8semarang.sch.id, password)
            activate Auth_Svr
            Auth_Svr-->>Svc: User Credential Created (UUID)
            deactivate Auth_Svr
            
            %% TAHAP 4: RECORD PROFILE RESMI
            Svc->>DB_Prof: INSERT INTO profiles (id, nis, username, full_name, class_group, role='user')
            activate DB_Prof
            DB_Prof-->>Svc: Profile Created Successfully
            deactivate DB_Prof
            
            Svc-->>Ctrl: Registrasi Sukses
            deactivate Svc
            Ctrl-->>UI: Emit State Sukses
            deactivate Ctrl
            UI-->>Siswa: Tampilkan Notifikasi Sukses & Arahkan ke Layar Login
        end
    end
