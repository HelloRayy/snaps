Peta Arsitektur Informasi Aplikasi

Penataan taksonomi menu, pemetaan alur hierarki data, dan rancangan skema navigasi sistem. Penerapan Arsitektur Informasi (IA) ini bertujuan meminimalkan beban kognitif (low cognitive load) agar pengguna dapat menyelesaikan tugas operasional dan administratif dengan langkah paling ringkas.

Prinsip Arsitektur

Struktur & Taksonomi Konten

Arsitektur Informasi menerapkan model Hub-and-Spoke berjenjang 3 tingkat:

  • Tier 0 (Root): Dashboard Utama sebagai titik masuk sentral.
  • Tier 1 (Modul): Pengelompokan 5 domain kerja independen.
  • Tier 2 (Leaf): Isolasi data master untuk integritas referensi POS.

Ergonomi Pengguna

Reduksi Beban Kognitif (Low Load)

Mengoptimalkan kecepatan kerja kasir dan administrator melalui jalur navigasi pendek:

  • Maksimal 2 ketukan (clicks) dari Dashboard menuju layar transaksi kasir.
  • Pemisahan tegas antara tugas transaksional rutin dan pengaturan administratif.
  • Hierarki visual mempercepat pengenalan fitur tanpa proses berpikir berlebih.

Integritas Alur Data

Keterikatan Alur Sistem

Peta data memastikan konsistensi transaksional:

  • Master Data mengunci dependensi Produk, Kategori, dan Profil Pengguna.
  • Transaksi POS mengalirkan data ke Riwayat Penjualan secara berurutan.
  • Riwayat Penjualan menjadi agregator tunggal untuk Laporan Keuangan.
